First public release of **Novastrap**, an open-source launcher for the Roblox desktop client on Windows.

Novastrap never asks for your Roblox password or cookies, doesn't inject anything into Roblox, and doesn't modify the Roblox executable.

## Download
- **`Novastrap_0.1.0_x64-setup.exe`:** the recommended installer.
- **`Novastrap_0.1.0_x64_en-US.msi`:** the same app, as an MSI package.

**Requirements:** Windows 10 or 11 (64-bit) with the Microsoft Edge WebView2 runtime. WebView2 is built into Windows 11; the installer sets it up on Windows 10 if it's missing.

**Unsigned build:** the installers aren't code-signed yet. Windows SmartScreen may say "Windows protected your PC / unknown publisher". Choose **More info → Run anyway** if you trust this release.

## What's included
- **Play:** install and update Roblox through Roblox's official signed installer, with its signature checked. Launch the Roblox app, join by place ID or link, or join a specific server. Rejoin your last game.
- **Instances:** saved launch setups, running clients with memory use, and closing a client.
- **Explore:** Roblox's trending and popular lists, search, genres, game pages, favorites, and recommendations based on your own history.
- **Servers:**
  - public servers with player count, server FPS and Roblox-reported ping;
  - favorite servers;
  - server history with Rejoin.
- **Performance:**
  - an editor for the FastFlags Roblox still accepts;
  - frame-rate cap and graphics quality;
  - presets and your own profiles, with import (Bloxstrap format too) and export;
  - diagnostics;
  - safe-mode launch.
- **Customize:**
  - three themes: Legacy 2019, Classic and Launcher;
  - accent color, font and background image;
  - compact mode, text size, sidebar order and hiding;
  - cursor and death-sound mods, with backups and one-click revert.
- **Marketplace:** catalog search and avatar preview. Item values from Rolimons (labelled as such) with a trade calculator.
- **Accounts:** Sign in with Roblox (official OAuth; needs your own OAuth client ID). Tokens are kept in Windows Credential Manager.
- **Desktop:**
  - system tray, with an option to keep Novastrap running when the window is closed;
  - global keyboard shortcuts (off by default);
  - notification center;
  - second-screen HUD window;
  - desktop shortcuts for games.
- **Discord Rich Presence:** needs a Discord application ID. Privacy switches included.
- **Settings:** storage usage and cleanup, a log viewer, backups (never including sign-in tokens), and update checks with Stable and Beta channels.

## Known limitations
- **Not possible within Novastrap's rules:**
  - running several Roblox clients at once (tested on client 0.747; Roblox hands the second one off to the first);
  - a different account per client, joining friends, and trade history: these need Roblox's session cookie, which Novastrap doesn't use;
  - FPS above 240.
- **No self-update or rollback yet.** Novastrap tells you when a release is out; download it from this page.
- **Not tested end to end:** Sign in with Roblox (needs your OAuth client ID), Rejoin and the Repair button.
