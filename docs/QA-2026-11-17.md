# QA report: post-expansion audit (2026-11-17)

**Method:** the real debug build was run with WebView2's debugging port open. A small DevTools client clicked the actual UI, read back what was on screen and in the settings files, and took screenshots. Window and keyboard behaviour was driven with real Windows messages and key presses. No mocks.

**Verdicts:**
- **Pass:** the feature did the right thing in the running app.
- **Partial:** part of it was exercised.
- **Not tested:** it could not be exercised here; the reason is given.

## Security and privacy review
- **Cookies:** no code reads, requests or stores Roblox cookies (searched the code).
- **Secrets:** sign-in tokens live only in Windows Credential Manager and aren't in backups. The Discord application ID and the OAuth client ID are public identifiers, not secrets. Logs don't print tokens.
- **Imported backups:**
  - format tag and 5 MB size limit checked;
  - settings fully validated (theme, fonts, accent, shortcuts, channel, sidebar, IDs);
  - invalid performance/instance profiles dropped;
  - mod entries kept only if the file exists locally;
  - account link state recomputed.

  Theme imports go through the same settings validation. Images from imported data can only load from `*.rbxcdn.com` (content security policy).
- **Updates:** Novastrap doesn't download or run its own updates. It only opens release pages, filtered to `https://github.com/`, through the external-link allowlist.
- **Executables:** only two things are ever run:
  - Roblox's official installer, after its Authenticode signature is confirmed as Roblox Corporation;
  - the installed Roblox player.

  The desktop shortcut file only contains Roblox's own link format.
- **Rendering:** nothing uses raw HTML. Release notes and notices render as text.

## Remaining opportunities
| Idea | Assessment |
|---|---|
| Download manager | Not useful: Novastrap downloads exactly one file type (the official installer), which already has progress, signature verification and resume cleanup |
| Storage analyzer | Exists (sizes per category + clearing). Could show per-folder detail; low value |
| Advanced backup/restore | Realistic: choose which parts to restore; include mod files in the backup |
| Configurable storage directory | Realistic for large data (downloads, mods, backgrounds); settings must stay in AppData |
| Multi-account via official sign-in | Already supported for profiles. Making the **Roblox client** use a different account still needs the session cookie, so that stays out of scope |
| Extension/plugin system | Possible but a large surface for security problems; would need a sandbox and a permission model. Not recommended yet |
| Accessibility | Next steps: keyboard focus order in the game modal, labels on icon-only buttons (mostly done), high-contrast check of the Classic theme |
| Localization | Needs an i18n layer across all pages and human-reviewed translations |
